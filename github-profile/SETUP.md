# Publish the profile

GitHub displays a profile README from a public repository whose name matches your username.

1. Create or open `vikramwish/vikramwish` on GitHub.
2. Copy this folder's `README.md` to the root of that repository.
3. Copy `assets/profile-header.svg` into an `assets` folder in that repository.
4. Commit both files to the repository's default branch.
5. Open `https://github.com/vikramwish` to see your profile.

If that repository already has a README, review and merge the content before replacing it.

The banner is a self-contained SVG with no external fonts, scripts, or image dependencies. GitHub controls the surrounding page colors and typography; the banner keeps its own white background in both light and dark themes.

Edit the text in `README.md` to personalize the introduction and priorities. The main nameplate uses Helvetica Neue Light, converted to vector paths so it renders consistently on GitHub. `assets/profile-header-editable.svg` keeps the original text for editing; it requires Helvetica Neue locally. Edit the published SVG directly for other labels and drawing details. This design was published to `vikramwish/vikramwish` in commit `ea426e0`; this folder retains the source assets for future edits.
